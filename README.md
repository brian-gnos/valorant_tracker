# Valorant Tracker

Site para buscar stats de jogadores do Valorant.

## Funcionalidades
- Busca por nick e tag
- Mostra nível, região e rank
- Histórico das últimas 5 partidas

## Tecnologias
- Python
- Flask
- HenrikDev API

## Como rodar

1. Instale as dependências:

pip install flask requests python-dotenv


2. Crie um arquivo ".env" com sua chave da API:

CHAVE=sua_chave_aqui


3. Rode o projeto:

python app.py
