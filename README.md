# Valorant Tracker

Site para buscar informações de jogadores do Valorant.

## Funcionalidades
- Busca a partir de nick e tag
- Mostra nível, região e rank e as últimas cinco partidas da conta

## Tecnologias
- Python
- Flask
- HTML/CSS
- HenrikDev API

## Como usar

1. Instale as dependências:
    pip install flask requests python-dotenv


2. Crie um arquivo ".env" com sua chave da API:
    CHAVE = sua_chave_aqui


3. Rode o projeto:
    python app.py
